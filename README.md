# X — Social Platform

A modern social platform interface built with React and JavaScript, inspired by the core interaction patterns of X.

The project was built to practice building a larger React application with reusable components, client-side state management, routing, interactive UI, media handling, and responsive layouts.

## Features

* Create and interact with posts
* User profiles
* Post detail views
* Media previews and uploads
* Interactive post actions
* Client-side navigation
* Chat interface
* Notifications
* Responsive layouts
* Reusable UI components
* Client-side state management
* Toast notifications and UI feedback
* Animated interactions

## Tech Stack

* React
* JavaScript
* Vite
* Tailwind CSS
* Zustand
* React Router
* Framer Motion
* Lucide React

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/ayo100x/X.git
```

Move into the project directory:

```bash
cd X
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
